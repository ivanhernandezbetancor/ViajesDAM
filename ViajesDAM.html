Actividad 9: ViajesDAM

Programación Multimedia y Dispositivos Móviles (2º DAM) · UT2 Diario de viajes con menú lateral, Room, navegación con parámetros y corrutinas

1. Enunciado

Objetivo

Desarrollar ViajesDAM, una aplicación Android para almacenar y consultar los viajes de un diario personal. La actividad sigue la misma arquitectura por capas que DAMFlix (Parte 7): MVVM + Room, con ViewModel y Factory independientes, rutas en una sealed class, un único Pantallas.kt en la raíz y las pantallas de catálogo y formulario en ui/screens.

Requisitos funcionales

Requisito Cómo se cumple
1. Inicio Pantalla de bienvenida con el nombre de la app
2. Alta de viaje Formulario con destino, país, año del viaje y casilla "Ya lo he visitado". El botón Guardar solo se habilita si destino y país no están vacíos y el año es un número válido
3. Catálogo LazyColumn con todos los viajes. Cada tarjeta tiene un icono de favorito y otro de eliminar, y toda la tarjeta es clicable
4. Detalle (Maestro-Detalle) Al pulsar una tarjeta se navega a "detalle/{viajeId}". La carga se hace con una corrutina en Dispatchers.IO y la pantalla muestra Cargando, Exito o Error
5. Perfil Cabecera con degradado, avatar circular con borde, nombre, rol, descripción y tres tarjetas de estadísticas (viajes, favoritos y visitados) calculadas con los datos de Room
6. Menú hamburguesa ModalNavigationDrawer con Inicio, Catálogo, Añadir Viaje y Perfil. El detalle no aparece en el menú

Requisitos técnicos

  • Paquete base com.example.viajesdam.
  • Prohibido escribir cadenas hardcoded: todos los textos de la interfaz en strings.xml y stringResource().
  • Clases de Room en el paquete model, junto al repositorio.
  • Flow en el DAO y StateFlow en el ViewModel con stateIn.
  • Base de datos y repositorio creados en una clase Application con by lazy.
  • Cada ViewModel tiene su propia clase ViewModelProvider.Factory.
  • Las pantallas no reciben el NavController: reciben lambdas (event hoisting).
  • La lectura de Room del detalle se ejecuta con withContext(Dispatchers.IO).
  • Estados del detalle con una sealed interface (Cargando, Exito, Error).
  • El mensaje de error llega al ViewModel como parámetro, porque el ViewModel no puede usar stringResource().

model/ViajeEntity.kt

package com.example.viajesdam.model

import androidx.room.Entity
import androidx.room.PrimaryKey

@Entity(tableName = "viajes")
data class ViajeEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,
    val destino: String,
    val pais: String,
    val anio: Int,
    val esVisitado: Boolean = false,
    val esFavorito: Boolean = false
)

model/ViajeDao.kt

package com.example.viajesdam.model

import androidx.room.Dao
import androidx.room.Delete
import androidx.room.Insert
import androidx.room.OnConflictStrategy
import androidx.room.Query
import androidx.room.Update
import kotlinx.coroutines.flow.Flow

@Dao
interface ViajeDao {

    // Al retornar Flow, Room notifica automáticamente cualquier cambio en la tabla
    @Query("SELECT * FROM viajes ORDER BY id DESC")
    fun obtenerTodos(): Flow<List<ViajeEntity>>

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertar(viaje: ViajeEntity)

    @Update
    suspend fun actualizar(viaje: ViajeEntity)

    @Delete
    suspend fun eliminar(viaje: ViajeEntity)

    // Consulta de un único viaje para la pantalla de detalle
    @Query("SELECT * FROM viajes WHERE id = :id")
    suspend fun obtenerPorId(id: Int): ViajeEntity?
}

model/AppDatabase.kt

package com.example.viajesdam.model

import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase

@Database(entities = [ViajeEntity::class], version = 1, exportSchema = false)
abstract class AppDatabase : RoomDatabase() {

    abstract fun viajeDao(): ViajeDao

    companion object {
        @Volatile
        private var INSTANCE: AppDatabase? = null

        fun getDatabase(context: Context): AppDatabase {
            return INSTANCE ?: synchronized(this) {
                val instance = Room.databaseBuilder(
                    context.applicationContext,
                    AppDatabase::class.java,
                    "viajesdam_room.db"
                ).build()
                INSTANCE = instance
                instance
            }
        }
    }
}

model/ViajeRepository.kt

package com.example.viajesdam.model

import kotlinx.coroutines.flow.Flow

class ViajeRepository(private val dao: ViajeDao) {

    val todosLosViajes: Flow<List<ViajeEntity>> = dao.obtenerTodos()

    suspend fun insertar(viaje: ViajeEntity) {
        dao.insertar(viaje)
    }

    suspend fun actualizar(viaje: ViajeEntity) {
        dao.actualizar(viaje)
    }

    suspend fun eliminar(viaje: ViajeEntity) {
        dao.eliminar(viaje)
    }

    suspend fun obtenerPorId(id: Int): ViajeEntity? {
        return dao.obtenerPorId(id)
    }
}

4.3. Capa ViewModel: viewmodel

viewmodel/ViajeViewModel.kt

package com.example.viajesdam.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.viajesdam.model.ViajeEntity
import com.example.viajesdam.model.ViajeRepository
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

class ViajeViewModel(private val repository: ViajeRepository) : ViewModel() {

    // Conversión del Flow de Room en StateFlow reactivo para Compose
    val listaViajes: StateFlow<List<ViajeEntity>> = repository.todosLosViajes
        .stateIn(
            scope = viewModelScope,
            started = SharingStarted.WhileSubscribed(5000),
            initialValue = emptyList()
        )

    fun agregarViaje(destino: String, pais: String, anio: Int, esVisitado: Boolean) {
        viewModelScope.launch {
            val nuevo = ViajeEntity(
                destino = destino,
                pais = pais,
                anio = anio,
                esVisitado = esVisitado
            )
            repository.insertar(nuevo)
        }
    }

    fun conmutarFavorito(viaje: ViajeEntity) {
        viewModelScope.launch {
            val actualizado = viaje.copy(esFavorito = !viaje.esFavorito)
            repository.actualizar(actualizado)
        }
    }

    fun eliminarViaje(viaje: ViajeEntity) {
        viewModelScope.launch {
            repository.eliminar(viaje)
        }
    }
}

viewmodel/DetalleViajeViewModel.kt

package com.example.viajesdam.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.viajesdam.model.ViajeRepository
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

class DetalleViajeViewModel(
    private val repository: ViajeRepository
) : ViewModel() {

    private val _uiState = MutableStateFlow<DetalleUiState>(DetalleUiState.Cargando)
    val uiState: StateFlow<DetalleUiState> = _uiState.asStateFlow()

    fun cargarDetalleViaje(viajeId: Int, mensajeNoEncontrado: String) {
        viewModelScope.launch {
            _uiState.value = DetalleUiState.Cargando

            val resultado = withContext(Dispatchers.IO) {
                delay(1000) // Simulación de retardo para apreciar el indicador de carga
                repository.obtenerPorId(viajeId)
            }

            if (resultado != null) {
                _uiState.value = DetalleUiState.Exito(resultado)
            } else {
                _uiState.value = DetalleUiState.Error(mensajeNoEncontrado)
            }
        }
    }
}

@Composable
fun FormularioAgregarViajeScreen(
    viewModel: ViajeViewModel,
    onViajeGuardado: () -> Unit = {},
    modifier: Modifier = Modifier
) {
    var destino by remember { mutableStateOf("") }
    var pais by remember { mutableStateOf("") }
    var anioTexto by remember { mutableStateOf("") }
    var esVisitado by remember { mutableStateOf(false) }

    val esFormularioValido = destino.isNotBlank() &&
            pais.isNotBlank() &&
            anioTexto.toIntOrNull() != null

    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        Text(
            text = stringResource(R.string.anadir_viaje),
            style = MaterialTheme.typography.headlineMedium
        )

        OutlinedTextField(
            value = destino,
            onValueChange = { destino = it },
            label = { Text(stringResource(R.string.destino_viaje)) },
            singleLine = true,
            modifier = Modifier.fillMaxWidth()
        )

        OutlinedTextField(
            value = pais,
            onValueChange = { pais = it },
            label = { Text(stringResource(R.string.pais_viaje)) },
            singleLine = true,
            modifier = Modifier.fillMaxWidth()
        )

        OutlinedTextField(
            value = anioTexto,
            onValueChange = { anioTexto = it },
            label = { Text(stringResource(R.string.anio_viaje)) },
            singleLine = true,
            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
            modifier = Modifier.fillMaxWidth()
        )

        Row(
            verticalAlignment = Alignment.CenterVertically,
            modifier = Modifier.fillMaxWidth()
        ) {
            Checkbox(checked = esVisitado, onCheckedChange = { esVisitado = it })
            Text(text = stringResource(R.string.viaje_visitado))
        }

        Spacer(modifier = Modifier.weight(1f))

        Button(
            onClick = {
                val anio = anioTexto.toIntOrNull() ?: 0
                viewModel.agregarViaje(
                    destino = destino,
                    pais = pais,
                    anio = anio,
                    esVisitado = esVisitado
                )
                destino = ""
                pais = ""
                anioTexto = ""
                esVisitado = false
                onViajeGuardado()
            },
            enabled = esFormularioValido,
            modifier = Modifier.fillMaxWidth()
        ) {
            Text(text = stringResource(R.string.guardar_viaje))
        }
    }
}

@Composable
fun AppViajesMainScreen(viewModel: ViajeViewModel) {
    val navController = rememberNavController()

    // 1. Estado del Drawer (abierto / cerrado)
    val drawerState = rememberDrawerState(initialValue = DrawerValue.Closed)

    // 2. CoroutineScope necesario para animar la apertura y el cierre
    val coroutineScope = rememberCoroutineScope()

    val navBackStackEntry by navController.currentBackStackEntryAsState()
    val rutaActual = navBackStackEntry?.destination?.route

    val opcionesMenu = listOf(Ruta.Inicio, Ruta.Catalogo, Ruta.Formulario, Ruta.Perfil)

    ModalNavigationDrawer(
        drawerState = drawerState,
        drawerContent = {
            ModalDrawerSheet {
                // Cabecera del menú lateral
                Box(modifier = Modifier.fillMaxWidth().padding(24.dp)) {
                    Text(
                        text = stringResource(R.string.cabecera_drawer),
                        style = MaterialTheme.typography.headlineMedium,
                        color = MaterialTheme.colorScheme.primary
                    )
                }
                HorizontalDivider()
                Spacer(modifier = Modifier.height(12.dp))

                // Opciones del menú
                opcionesMenu.forEach { opcion ->
                    NavigationDrawerItem(
                        icon = { Icon(opcion.icono, contentDescription = stringResource(opcion.titulo)) },
                        label = { Text(stringResource(opcion.titulo)) },
                        selected = rutaActual == opcion.path,
                        onClick = {
                            // Cierre asíncrono del panel
                            coroutineScope.launch { drawerState.close() }
                            if (rutaActual != opcion.path) {
                                navController.navigate(opcion.path) {
                                    popUpTo(navController.graph.startDestinationId) { saveState = true }
                                    launchSingleTop = true
                                    restoreState = true
                                }
                            }
                        },
                        modifier = Modifier.padding(NavigationDrawerItemDefaults.ItemPadding)
                    )
                }
            }
        }
    ) {
        // Contenido principal envuelto en Scaffold
        Scaffold(
            topBar = {
                TopAppBar(
                    title = { Text(stringResource(R.string.titulo_app)) },
                    navigationIcon = {
                        // Botón de hamburguesa para abrir el Drawer
                        IconButton(onClick = { coroutineScope.launch { drawerState.open() } }) {
                            Icon(Icons.Default.Menu, contentDescription = stringResource(R.string.abrir_menu))
                        }
                    },
                    colors = TopAppBarDefaults.topAppBarColors(
                        containerColor = MaterialTheme.colorScheme.primaryContainer
                    )

                        }

6. Preguntas de comprensión

  1. ¿Por qué ViajeViewModel y DetalleViajeViewModel necesitan una Factory propia?
  2. ¿Por qué el mensaje de error del detalle llega por parámetro y no se escribe dentro del ViewModel?
  3. ¿Qué diferencia hay entre Flow en obtenerTodos() y suspend en obtenerPorId()? ¿Por qué cada una se declara así?
  4. ¿Por qué las estadísticas del perfil se actualizan solas?
  5. ¿Qué ocurre si en el NavHost se registra ListaViajesScreen(viewModel, {})?
  6. ¿Para qué sirven @Volatile y synchronized en AppDatabase?
  7. ¿Por qué drawerState.open() se llama dentro de coroutineScope.launch { }?

Respuestas

  1. viewModel() solo puede crear clases con constructor vacío. Estos ViewModels reciben un ViajeRepository, así que la Factory indica cómo construirlos y permite que Compose los retenga ante rotaciones.
  2. El ViewModel no tiene acceso a stringResource(). La pantalla lee el texto de strings.xml y se lo pasa, así no hay cadenas escritas en el código.
  3. obtenerTodos() devuelve un Flow porque la lista debe actualizarse sola cada vez que cambie la tabla. obtenerPorId() es suspend porque se ejecuta una sola vez y puede devolver null si el id no existe.
  4. El DAO devuelve un Flow: Room emite la lista nueva cuando la tabla cambia, el ViewModel la expone como StateFlow y el perfil, que cuenta sobre esa lista, se recompone.
  5. Al pulsar una tarjeta se ejecuta un bloque vacío: el evento se pierde y no se navega. Hay que conectar la lambda con navController.navigate(Ruta.Detalle.crearRuta(viajeId)).
  6. @Volatile hace visible INSTANCE para todos los hilos y synchronized evita crear dos instancias de la base de datos a la vez.
  7. open() y close() son funciones suspend que animan el panel, así que necesitan un ámbito de corrutina obtenido con rememberCoroutineScope().
